# 部署与推广成本测算：课旁

> 测算日期：2026-10-18  
> 口径：文字通知 MVP、50–100 名用户、3 个月小范围验证。  
> 说明：以下是现金成本估算，不含人力时间；云厂商和学生优惠会显著影响实际支出。

## 1. 测算假设

- 产品形态：微信客服助手 + 微信小程序。
- 第一版只做文字通知识别，不做图片通知、图片课表、合并转发。
- 数据库和 Redis 先自建在云服务器上，不上托管版。
- 企业微信客服先不认证，用未认证的 100 客户额度做小范围测试。
- 小程序需要企业/组织主体认证；如果能挂靠学校/公司，主体成本为 0。
- 推广以班级群、朋友圈、社团转发和海报为主，不投付费广告。
- 用户规模按 50 人做基准，100 人做上限。

## 2. 部署成本

### 2.1 一次性投入

| 项目 | 预算 | 说明 |
|---|---:|---|
| 域名 | 50–100 元/年 | .com 或 .cn；备案免费 |
| SSL 证书 | 0 元 | Let's Encrypt 或云厂商免费证书 |
| 小程序认证 | 300 元/年 | 企业/组织主体；个人主体不能认证 |
| 企业微信认证 | 0–300 元/年 | 未认证累计 100 客户，小范围测试可不认证 |
| 主体注册 | 0–1000 元 | 有学校/公司挂靠则 0；个体户自行注册通常免费，代办 500–1000 |
| 隐私政策/法务 | 0–1000 元 | 可用模板自检；律师复核另算 |
| 设计/原型工具 | 0–100 元 | Figma/Coze 免费额度通常够用 |
| 打印物料 | 50–200 元 | 100–200 份 A5 海报/传单/二维码贴纸 |
| 测试用户激励 | 100–300 元 | 10 名深度测试用户 × 10–20 元 |

**小计：约 200–1500 元**，取决于是否自有主体、是否找律师、是否认证企微。

### 2.2 月度运行

| 项目 | 预算/月 | 说明 |
|---|---:|---|
| 云服务器 | 60–150 元 | 2C2G/2C4G 轻量服务器；新用户年付更低 |
| 数据库 | 0–100 元 | MVP 自建 MySQL 可为 0；托管 RDS 约 50–100 |
| Redis | 0–50 元 | 可自建；也可以先不用 |
| 对象存储 | 5–20 元 | 课表文件/图片，按量 |
| 大模型 API | 20–100 元 | 按 0.01–0.05 元/条；50 人 × 10 条/月约 25–50 元 |
| OCR | 0–50 元 | 第一版只做文字，可为 0 |
| 监控/日志 | 0 元 | 免费额度够用 |
| 域名/证书摊销 | 5–10 元 | 年费摊到月 |

**小计：约 90–430 元/月。** 极简配置约 100–200 元/月，托管数据库 + Redis 约 250–430 元/月。

## 3. 推广成本

按 50–100 人、3 个月：

| 项目 | 预算 | 说明 |
|---|---:|---|
| 班级群/朋友圈/社团转发 | 0 元 | 主要渠道，靠同学关系 |
| 海报/传单/二维码贴纸 | 50–200 元 | 打印 100–200 份 |
| 测试用户红包/小礼品 | 100–300 元 | 深度测试用户激励 |
| 校园墙/社团合作 | 0–500 元 | 小礼品或联合活动 |
| 内容制作 | 0 元 | 自己写/拍，不找代运营 |
| 付费广告 | 0 元 | 小范围验证阶段不建议投 |

**小计：约 150–1000 元**，按 50 人算约 3–20 元/人。

## 4. 三档预算

| 档位 | 适用场景 | 一次性 | 3 个月运行 | 推广 | 合计 |
|---|---|---:|---:|---:|---:|
| 极简验证 | 30–50 人，1–2 个月，只验证核心链路 | 200–500 | 200–400 | 100–300 | **500–1200 元** |
| 小范围公测 | 50–100 人，3 个月，有海报和红包 | 500–1500 | 600–1200 | 300–800 | **1500–3500 元** |
| 规范上线 | 100 人，3 个月，自有主体 + 法务 + 托管数据库 | 2000–4000 | 1200–2400 | 500–1500 | **4000–8000 元** |

> 不含开发人力。如果找外包开发，另加 5000–30000 元；自己用 AI 写，主要成本是时间。

## 5. 单用户与单条成本

按 50 人、3 个月、总成本 2000 元：

- 试点期：约 **40 元/用户**（含一次性部署和推广）。
- 稳定运行后：约 **3–5 元/用户/月**（服务器 + 模型 + 存储）。
- 单条通知识别：约 **0.01–0.05 元/条**；每人每月转发 10 条，模型成本约 0.1–0.5 元/人/月。

按 100 人、3 个月、总成本 3000 元：

- 试点期：约 **30 元/用户**。
- 稳定运行后：约 **2.5–4 元/用户/月**。

## 6. 比费用更容易卡住的事

1. **主体资质。** 微信客服需要企业/组织主体；个人小程序不能认证、不能接客服。学生团队优先找学校创业园/实验室/公司挂靠，或注册个体户。
2. **备案周期。** 小程序备案 + 域名 ICP 备案免费，但需要 1–20 个工作日；不要等开发完才办。
3. **微信客服能力。** 单条转发能否拿到完整内容、会话次日能否找回，还没真机验证。这两项不通过，推广物料和开发投入都可能白花。
4. **合规。** 隐私政策、PIA、AI 标注、数据留存；公开推广前至少把隐私政策和备案做完。
5. **客服客户数上限。** 未认证企业微信累计 100 客户；小范围测试够用，超过 100 需认证。

## 7. 建议的花钱顺序

1. **先花 0–300 元做 M0 验证**：真机转发、7 条通知抽取、5 人 Concierge。没通过就不部署。
2. **通过后再花 500–1000 元部署**：域名、服务器、小程序认证、隐私政策。
3. **最后花 300–800 元推广**：海报、红包、班级群。不要在验证前印海报、投广告。

## 8. 可以压缩的成本

- 用学校/公司主体，省掉主体注册和部分认证费用。
- 用云厂商学生优惠/新用户年付，服务器可压到 100–200 元/年。
- 数据库、Redis 先自建，不买托管版。
- 企业微信先不认证，小范围测试用 100 客户额度。
- 用 Coze/Figma 免费额度做原型，不买付费席位。
- 用免费 SSL、免费监控额度、免费 LLM 试用额度。
- 推广先走班级群和社团，不投付费广告。

## 9. 面试/汇报口径

> 3 个月、50–100 人的小范围验证，现金成本约 1500–3000 元，主要是服务器、域名、认证和推广物料；不含人力。最大的不确定性不是费用，而是主体资质、备案周期，以及微信客服转发能力是否成立。所以我会先花 0–300 元做 M0 验证，通过后再部署和推广。

## 10. 待确认项

- [ ] 是否能挂靠学校/公司主体，还是需要注册个体户。
- [ ] 小程序认证和企业微信认证是否同时需要。
- [ ] 云厂商学生优惠/新用户优惠的实际价格。
- [ ] 大模型选型后的真实单价和免费额度。
- [ ] 是否需要律师复核隐私政策。
- [ ] 小范围推广的实际人数和激励方式。
