# 小排 · 产品面试项目

> **把项目、群消息丢进来，小排帮你排好。**

## 一句话介绍

小排是一个微信小程序：把微信/QQ 群消息、项目说明或一段待办粘贴进来，AI 自动拆成任务、日程和 DDL，按截止时间、优先级和空闲时间排进日历；用户确认或拖拽后保存，打开小程序就知道今天做什么。

课表导入是次要能力；每日提醒放到 V1，MVP 先验证「粘贴 → 自动排期」这条核心链路。

## 目标用户

- **主要（MVP）**：事务密度高的大学生——学生干部、社团负责人、竞赛/科研/实习多、课程和群通知多的人
- **次要（后续）**：初入职场、项目执行型岗位（需要飞书/企微/Outlook 日历，放到学生验证之后）
- **非目标**：需要团队协作、任务分派、甘特图、资源排班的团队；只需要简单待办的人

## 用户问题

1. 群消息、项目说明散落，手动拆时间、地点、截止日期成本高；
2. 知道 DDL，但不知道从哪天开始做、每次做多久；
3. 日程、任务、DDL 混在一起，优先级不清；
4. 每天要重新想一遍「今天做什么」。

## 产品方案

- **输入**：微信小程序内粘贴微信/QQ 消息、项目说明或待办；复制/粘贴是主入口，不读取聊天记录；
- **抽取**：识别任务、日程、DDL，补全时间、地点、优先级、预计时长、依赖关系；
- **确认**：卡片可编辑，低置信度必须确认，不静默写入；
- **排期**：按截止时间、优先级、空闲时间自动放任务块，给出「为什么排在这里」，用户可拖拽/锁定；
- **查看**：今日、周视图、项目视图、DDL 栏、逾期标红；
- **提醒**：MVP 只做打开小程序时的「今日」视图；V1 再做每日早报和按任务节奏提醒（微信服务号/订阅消息，受平台限制）；
- **课表**：次要能力，后续支持固定课程作为日历底图，不做 MVP 验收项。

## 差异化

- 从「中文消息/项目说明」直接到「可执行排期」，不是又一个待办清单；
- 自动排期 + 解释 + 可拖拽，不黑箱；
- 微信内闭环，复制粘贴即可，不要求读取聊天记录；
- 先服务事务多的学生，不泛化做团队协作；
- 课表、社区、广告都不做核心。

## 2026-10-18 产品转型说明

项目原名为「课旁」，核心是「课表 + 群通知识别」。本次转型后：

- 产品名改为 **小排**；
- 核心竞争力改为 **把项目/消息自动排进日历、标 DDL、形成今日待办**；
- 课表导入降为次要能力；
- 目标用户从「在校大学生」扩大到「事务多的学生 + 后续上班族」；
- MVP 不做每日提醒，只做今日视图；
- 目录名暂保留，避免破坏现有文件；早期文档中的「课旁/课表」是转型前研究，保留作为证据，新 PRD 以「小排」为准。

## 下一步（按优先级）

1. **补访谈**：3–5 名事务多的学生，重点问「最近一次收到项目/通知后怎么安排」「愿不愿意粘贴一段文字换排期」；
2. **评测搬出 Coze**：Coze 阶段已收口（进阶版额度用尽）。按[Coze 测试研究发现总结](06-研究发现/Coze测试研究发现总结.md)把 7 条回归迁到本地/后端脚本，固定 Prompt、基准日、输入和参数，逐次保存完整输出；扩样前不写总体准确率；
3. **跑原型 pilot**：打开 [可点击原型 v1](09-Figma原型/小排-HTML原型.html)，按 [使用说明](09-Figma原型/README.md) 和 [2 人 pilot 记录表](10-用户测试/pilot记录.md) 跑 2–3 人；A/B 确认方式在同一批用户内对比；
4. **验排期**：记录排期接受率、拖拽原因、排不下时的处理；
5. **定 V1 提醒渠道**：服务号模板消息 / 小程序订阅消息 / 邮件或日历兜底，先小范围验证；
6. **课表 P2**：不抢 MVP 资源，等核心链路成立后再做；
7. 以上通过后再写小程序 MVP 代码。

## 面试怎么讲（3 分钟版）

1. **问题来源**：我长期在群里收通知、在备忘录里记 DDL，发现真正麻烦的不是「记下来」，而是「记下来之后没有计划」；
2. **转型**：原来做课表 + 通知识别，后来把核心改成「从消息/项目说明直接生成排期」，课表降为次要；
3. **方案**：微信小程序粘贴 → AI 拆任务/日程/DDL → 确认 → 按截止/优先级/空闲时间自动排期 → 今日视图；排期可解释、可拖拽；
4. **验证**：已完成 7 条真实输入的 v1→v3 多轮回归和 deadline 专项；单次 7/7，但 7×3 只有 15/21，说明要用确认卡片和工程兜底，而不是宣称零确认；下一步用 2–3 人 pilot 测「愿不愿意粘贴、接不接受自动排期」，最后 10–20 人看第 2 周回访；
5. **边界**：MVP 不做每日提醒（微信推送受限），不做团队协作，不读聊天记录；课表 P2；
6. **差异化**：中文消息/项目说明直接变成排期，不是又一个待办清单；先服务事务多的学生。
